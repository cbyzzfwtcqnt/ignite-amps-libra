## Overview

Libra is a free mastering limiter with true-peak detection, integrated LUFS metering, a look-ahead algorithm, and a soft-knee mode for transparent limiting on the final mix bus.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Ignite Amps Libra** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **True-Peak Limiting** | Oversampled true-peak detection prevents ISP on streaming platforms |
| **LUFS Metering** | Integrated LUFS-I and LUFS-S meters for loudness targeting |
| **Look-Ahead** | Configurable look-ahead window from 0 to 20ms for natural response |
| **Soft Knee** | Optional soft-knee mode for transparent limiting at moderate ceiling |
